# Dataset

## Source
- **Platform:** Kaggle
- **Dataset:** Google Play Store Apps
- **URL:** https://www.kaggle.com/datasets/lava18/google-play-store-apps

## Description
A Google Play Store app catalogue containing fields such as category, rating, reviews, size, installs, type, price, content rating, genres, and last update information. The raw data contains inconsistencies and missing values that make it useful for a data-cleaning exercise.

## Intended use
Assess data quality, identify missing/invalid values, standardize data types and representations, handle duplicates, and produce a documented analytical-ready dataset.

## Files
Download `googleplaystore.csv` from Kaggle and place it in this directory. Raw datasets are intentionally excluded from Git via the repository `.gitignore`.

## Reproducibility
Record the dataset version/date used for the final cleaning pipeline in the project README or notebook metadata.
