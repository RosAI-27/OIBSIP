## Workflow

1. Add the dataset locally; do not commit large or restricted datasets.
2. Complete the notebook with reproducible analysis and written observations.
3. Save important figures in `outputs/`.
4. Update the project README with methods, findings, and limitations.
5. Review the notebook before marking the project complete.

> Status is intentionally kept separate from the project notebooks so the repository can evolve as work is completed.
