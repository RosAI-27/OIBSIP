# Dataset

## Source
- **Platform:** Kaggle
- **Dataset:** Google Play Store Apps
- **URL:** https://www.kaggle.com/datasets/lava18/google-play-store-apps

## Description
Google Play Store app catalogue data containing variables such as app category, rating, number of reviews, size, installs, type, price, content rating, genres, and last update date. The associated Kaggle dataset also provides a separate user-review file.

## Intended use
Analyse the Android app marketplace: compare categories, ratings, reviews, installs, free versus paid apps, prices, and other available attributes to identify patterns associated with app popularity and market positioning.

## Files
Download `googleplaystore.csv` and, if required for the project scope, `googleplaystore_user_reviews.csv` from Kaggle and place them in this directory. Raw datasets are intentionally excluded from Git via the repository `.gitignore`.

## Reproducibility
Record the dataset version/date and the exact files used for the final analysis in the project README or notebook metadata.
