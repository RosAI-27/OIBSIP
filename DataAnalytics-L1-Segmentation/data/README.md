# Dataset

## Source
- **Platform:** Kaggle
- **Dataset:** Online Retail Dataset
- **URL:** https://www.kaggle.com/datasets/ersany/online-retail-dataset

## Description
Transaction-level online retail data suitable for customer-level aggregation, RFM (Recency, Frequency, Monetary) analysis, customer segmentation, and clustering.

## Intended use
Build customer-level RFM features and apply an interpretable segmentation approach such as K-Means, followed by segment profiling and business recommendations.

## Files
Download the dataset from Kaggle and place the required source file in this directory. Raw datasets are intentionally excluded from Git via the repository `.gitignore`.

## Reproducibility
Record the dataset version/date used for the final analysis in the project README or notebook metadata.
