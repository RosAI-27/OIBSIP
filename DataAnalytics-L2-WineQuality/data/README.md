# Dataset

## Source
- **Platform:** Kaggle
- **Dataset:** Wine Quality Dataset
- **URL:** https://www.kaggle.com/datasets/yasserh/wine-quality-dataset

## Description
Wine-quality data containing physicochemical measurements such as acidity, residual sugar, chlorides, sulphates, alcohol, and a quality score. The dataset can support classification or regression depending on the target definition.

## Intended use
Explore the relationship between physicochemical characteristics and wine quality, prepare the data, build an appropriate predictive baseline, evaluate it carefully, and interpret important features.

## Files
Download the dataset from Kaggle and place the required CSV file in this directory. Raw datasets are intentionally excluded from Git via the repository `.gitignore`.

## Reproducibility
Record the dataset version/date and the target formulation used for the final analysis in the project README or notebook metadata.
