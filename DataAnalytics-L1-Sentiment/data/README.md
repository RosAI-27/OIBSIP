# Dataset

## Source
- **Platform:** Kaggle
- **Dataset:** Google Play Store Reviews
- **URL:** https://www.kaggle.com/datasets/prakharrathi25/google-play-store-reviews

## Description
Google Play Store user reviews paired with app information/rating data. The review text can be used for text preprocessing, exploratory sentiment analysis, TF-IDF features, and sentiment classification.

## Intended use
Clean and inspect review text, define a reproducible sentiment target, explore sentiment patterns, and build/evaluate a suitable text-classification baseline.

## Files
Download the required review CSV from Kaggle and place it in this directory. Raw datasets are intentionally excluded from Git via the repository `.gitignore`.

## Reproducibility
Record the dataset version/date used for the final analysis in the project README or notebook metadata.
