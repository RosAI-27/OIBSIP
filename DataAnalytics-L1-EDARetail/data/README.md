# Dataset

## Source
- **Platform:** Kaggle
- **Dataset:** Retail Sales Dataset
- **Author:** Arjun Kumar (devbr22)
- **URL:** https://www.kaggle.com/datasets/devbr22/retail-sales-dataset

## Description
Retail transaction data containing transaction/customer identifiers, dates, demographics, product categories, quantities, unit prices, and total sales. It is suitable for sales trends, customer behaviour, product performance, and business-oriented EDA.

## Files
Download the dataset from Kaggle and place the required CSV file in this directory. Raw datasets are intentionally excluded from Git via the repository `.gitignore`.

## Reproducibility
Record the downloaded dataset version/date used for the final analysis in the project README or notebook metadata.
