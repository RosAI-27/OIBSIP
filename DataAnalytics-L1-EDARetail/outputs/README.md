# Analysis Outputs

These CSV files contain the validated analytical tables generated from `Retail_Sales.csv` and used to support the conclusions in the EDA notebook.

- `descriptive_statistics.csv` — mean, median, mode and standard deviation.
- `monthly_sales.csv` — monthly revenue, transaction count, quantity sold, profit and average transaction value.
- `quarterly_sales.csv` — quarterly revenue, transaction count, quantity sold and profit.
- `category_performance.csv` — revenue, volume, average transaction value, profit and margin by category.
- `gender_performance.csv` — revenue and transaction metrics by gender.
- `age_group_performance.csv` — customer, transaction and revenue metrics by age group.
- `customer_revenue_concentration.csv` — customer-level revenue ranking and cumulative revenue share.
- `correlation_matrix.csv` — Pearson correlation matrix for numerical variables.

The PNG charts are generated locally from the notebook/source script and can be added to this folder after execution if desired.
