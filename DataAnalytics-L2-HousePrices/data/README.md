# Dataset

## Source
- **Platform:** Kaggle
- **Dataset:** House Prices - Advanced Regression Techniques
- **Competition:** House Prices: Advanced Regression Techniques
- **URL:** https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

## Description
Residential property data with numerous structural, quality, location, and sale-related variables. The official Kaggle competition uses these features to predict `SalePrice`.

## Intended use
Perform data understanding and preprocessing, establish a regression baseline, compare suitable models, evaluate with an appropriate regression metric, and interpret the main drivers of predicted house prices.

## Files
Download the official competition data from Kaggle and place the required files in this directory. Raw datasets are intentionally excluded from Git via the repository `.gitignore`.

## Reproducibility
Record the dataset version/date and any competition-data split used for the final analysis in the project README or notebook metadata.
